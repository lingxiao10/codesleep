## What is CodeSleep?

CodeSleep is a VSCode extension that codes for you while you sleep!

## Why CodeSleep?

| Traditional AI Coding | CodeSleep |
|----------------------|-----------|
| Must wait and manually input each task one by one | **🔄 Sequential Tasks (Unattended)**: Set up multiple tasks once, auto-execute in sequence—no supervision needed |
| Choose one model: cheap = poor quality, premium = expensive | **💰 Large & Small Model Reduce AI Cost**: Cheap model reads/analyzes, premium model writes code, save 95% AI Cost |
| Must sit at your computer to operate | **📱 Work from Bed**: Create and manage dev tasks remotely from your phone |

### 🌙 The Philosophy
**CodeSleep = Code While You Sleep = Sequential Tasks (Unattended) + Large & Small Model Reduce AI Cost + Work from Bed**
