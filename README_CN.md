## CodeSleep 是什么？

CodeSleep 是一个 VSCode 插件，可以在你睡觉时替你完成写代码的任务！

## 为什么选择 CodeSleep？

| 传统 AI 编码 | CodeSleep |
|-------------|-----------|
| 必须守在旁边，等待完成一个任务，再手动输入下一个 | **🔄 序列任务（无需值守）**：一次安排多个任务，自动按序列执行——无需值守 |
| 只能选一个模型：便宜的太拉胯，高级的太贵 | **💰 大小模型降低AI成本**：便宜模型负责阅读分析，高级模型负责写代码，节省95% AI成本 |
| 必须坐在电脑前操作 | **📱 躺床上工作**：可通过手机远程创建和管理开发任务 |

### 🌙 核心理念
**CodeSleep = Code While You Sleep = 序列任务（无需值守）+ 大小模型降低AI成本 + 躺床上工作**

## 安装

**方式 1：从市场安装（推荐）**

访问 https://marketplace.visualstudio.com/items?itemName=devokaicode.codesleepai 安装 VSCode 插件

**方式 2：从源码构建**

1. 克隆仓库
2. 在根目录运行 `npm install`
3. 点击 `build.bat` 构建项目
4. 用 VSCode 打开项目
5. 按 `F5` 在调试模式下启动插件

## 发布

发布插件：
1. 进入 `packages/vscode-extension/` 目录
2. 点击 `publish.bat`
