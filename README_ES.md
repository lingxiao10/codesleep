## ¿Qué es CodeSleep?

CodeSleep es una extensión de VSCode que programa por ti mientras duermes.

## ¿Por qué CodeSleep?

| Codificación AI Tradicional | CodeSleep |
|------------------------------|-----------|
| Debes esperar e ingresar manualmente cada tarea una por una | **🔄 Tareas Secuenciales (Desatendido)**: Configura múltiples tareas una vez, ejecución automática en secuencia—sin supervisión necesaria |
| Elige un modelo: barato = mala calidad, premium = caro | **💰 Modelo Grande y Pequeño Reducen Costo de IA**: Modelo barato lee/analiza, modelo premium escribe código, ahorra 95% del costo de IA |
| Debes sentarte en tu computadora para operar | **📱 Trabajar desde la Cama**: Crea y gestiona tareas de desarrollo remotamente desde tu teléfono |

### 🌙 La Filosofía
**CodeSleep = Programa Mientras Duermes = Tareas Secuenciales (Desatendido) + Modelo Grande y Pequeño Reducen Costo de IA + Trabajar desde la Cama**

## Instalación

**Opción 1: Instalar desde Marketplace (Recomendado)**

Visita https://marketplace.visualstudio.com/items?itemName=devokaicode.codesleepai para instalar la extensión de VSCode

**Opción 2: Compilar desde Código Fuente**

1. Clona el repositorio
2. Ejecuta `npm install` en el directorio raíz
3. Haz clic en `build.bat` para compilar el proyecto
4. Abre el proyecto en VSCode
5. Presiona `F5` para iniciar la extensión en modo de depuración

## Publicación

Para publicar la extensión:
1. Navega a `packages/vscode-extension/`
2. Haz clic en `publish.bat`
