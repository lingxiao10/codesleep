## CodeSleepとは？

CodeSleepは、あなたが寝ている間にコーディングしてくれるVSCode拡張機能です。

## なぜCodeSleep？

| 従来のAIコーディング | CodeSleep |
|---------------------|-----------|
| 各タスクを一つずつ手動で入力して待つ必要がある | **🔄 シーケンシャルタスク（無人対応）**：複数のタスクを一度に設定、順番に自動実行—監視不要 |
| 一つのモデルを選択：安い=品質が悪い、プレミアム=高い | **💰 大小モデルがAIコストを削減**：安いモデルが読み取り/分析、プレミアムモデルがコード記述、AIコストを95%削減 |
| コンピュータの前に座って操作する必要がある | **📱 ベッドで作業**：スマホから開発タスクをリモートで作成・管理 |

### 🌙 哲学
**CodeSleep = 寝ている間にコーディング = シーケンシャルタスク（無人対応）+ 大小モデルがAIコストを削減 + ベッドで作業**

## インストール

**オプション1：マーケットプレイスからインストール（推奨）**

https://marketplace.visualstudio.com/items?itemName=devokaicode.codesleepai にアクセスしてVSCode拡張機能をインストール

**オプション2：ソースからビルド**

1. リポジトリをクローン
2. ルートディレクトリで `npm install` を実行
3. `build.bat` をクリックしてプロジェクトをビルド
4. VSCodeでプロジェクトを開く
5. `F5` を押してデバッグモードで拡張機能を起動

## 公開

拡張機能を公開するには：
1. `packages/vscode-extension/` に移動
2. `publish.bat` をクリック
