## O que é CodeSleep?

CodeSleep é uma extensão do VSCode que codifica para você enquanto você dorme.

## Por que CodeSleep?

| Codificação AI Tradicional | CodeSleep |
|----------------------------|-----------|
| Deve esperar e inserir manualmente cada tarefa uma por uma | **🔄 Tarefas Sequenciais (Sem Supervisão)**: Configure múltiplas tarefas uma vez, execução automática em sequência—sem supervisão necessária |
| Escolha um modelo: barato = má qualidade, premium = caro | **💰 Modelo Grande e Pequeno Reduzem Custo de IA**: Modelo barato lê/analisa, modelo premium escreve código, economiza 95% do custo de IA |
| Deve sentar no seu computador para operar | **📱 Trabalhar da Cama**: Crie e gerencie tarefas de desenvolvimento remotamente do seu telefone |

### 🌙 A Filosofia
**CodeSleep = Codifique Enquanto Dorme = Tarefas Sequenciais (Sem Supervisão) + Modelo Grande e Pequeno Reduzem Custo de IA + Trabalhar da Cama**

## Instalação

**Opção 1: Instalar do Marketplace (Recomendado)**

Visite https://marketplace.visualstudio.com/items?itemName=devokaicode.codesleepai para instalar a extensão do VSCode

**Opção 2: Compilar do Código Fonte**

1. Clone o repositório
2. Execute `npm install` no diretório raiz
3. Clique em `build.bat` para compilar o projeto
4. Abra o projeto no VSCode
5. Pressione `F5` para iniciar a extensão em modo de depuração

## Publicação

Para publicar a extensão:
1. Navegue até `packages/vscode-extension/`
2. Clique em `publish.bat`
