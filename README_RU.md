## Что такое CodeSleep?

CodeSleep — это расширение VSCode, которое программирует за вас, пока вы спите.

## Почему CodeSleep?

| Традиционное AI Программирование | CodeSleep |
|----------------------------------|-----------|
| Необходимо ждать и вручную вводить каждую задачу одну за другой | **🔄 Последовательные Задачи (Без Участия)**: Настройте несколько задач один раз, автоматическое выполнение по порядку—без надзора |
| Выберите одну модель: дешевая = плохое качество, премиум = дорого | **💰 Большая и Малая Модель Снижают Затраты на ИИ**: Дешевая модель читает/анализирует, премиум модель пишет код, экономия 95% затрат на ИИ |
| Необходимо сидеть за компьютером для работы | **📱 Работа с Кровати**: Создавайте и управляйте задачами разработки удаленно с телефона |

### 🌙 Философия
**CodeSleep = Программируйте, Пока Спите = Последовательные Задачи (Без Участия) + Большая и Малая Модель Снижают Затраты на ИИ + Работа с Кровати**

## Установка

**Вариант 1: Установка из Marketplace (Рекомендуется)**

Посетите https://marketplace.visualstudio.com/items?itemName=devokaicode.codesleepai для установки расширения VSCode

**Вариант 2: Сборка из Исходного Кода**

1. Клонируйте репозиторий
2. Выполните `npm install` в корневом каталоге
3. Нажмите `build.bat` для сборки проекта
4. Откройте проект в VSCode
5. Нажмите `F5` для запуска расширения в режиме отладки

## Публикация

Для публикации расширения:
1. Перейдите в `packages/vscode-extension/`
2. Нажмите `publish.bat`
